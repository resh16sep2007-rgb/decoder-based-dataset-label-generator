Decoder-Based
Dataset Label Generator

Learn and interact with a 3-to-8 decoder that converts binary input combinations into class labels and generates a balanced dataset.

PROBLEM STATEMENT

Introduction

Design a software solution that uses the 3-to-8 decoder concept to convert three-bit binary combinations into unique class labels and reproducible one-hot outputs for structured dataset generation.

SOFTWARE SOLUTION

Working Principle

01

Input

Three binary inputs A, B and C are supplied.

02

Decode

One of eight outputs becomes active.

03

Label

The active output maps to Class_0–Class_7.

04

Generate

Ten samples are created for every class.
